<p>基于 <b>Shizuku</b> 与 <b>Material 3 Expressive</b> 构建的 Android 敏感权限审计与 AppOps 管控工具 —— 无需 Root 权限，即可精细管理各类应用的敏感行为，并提供实时拦截提醒、审计日志与社区规则订阅能力。</p>

<p><b>核心特性</b></p>
<ul>
<li><b>免 Root 底层管控：</b>通过 Shizuku 获取特权 Shell（UID 2000）与 <code>IAppOpsService</code> 代理，支持调整 AppOps 模式（允许 / 忽略 / 拒绝 / 默认）并同步管理运行时权限。</li>
<li><b>四大敏感权限分类：</b>
  <ul>
  <li>传感器与运动：身体与运动传感器、身体活动识别（有效屏蔽“摇一摇”广告触发）。</li>
  <li>剪贴板与隐私：读取/写入剪贴板、读取已安装应用列表、使用情况统计。</li>
  <li>后台与唤醒：后台运行、任意后台活动、WakeLock 唤醒锁、开机自启。</li>
  <li>系统与安全：显示在其他应用上层（悬浮窗）、修改系统设置、通知监听。</li>
  </ul>
</li>
<li><b>实时拦截守护：</b>后台服务同时监听 <code>opNoted</code> 与 <code>opStarted</code> 拦截事件，记录审计日志，并支持 Toast、系统通知、Android 16+ 实时更新（Live Updates）及限时“临时允许”放行。</li>
<li><b>批量预设与社区规则：</b>内置常用批量防追踪与省电预设，支持订阅社区规则仓库（如 GraceThings/app-oops-rules 的 GitHub 或 Gitee 官方镜像）、在详情页展示已套用规则标签，并可一键导出规则 JSON 提交贡献。</li>
<li><b>Expressive 视觉与多语言：</b>支持动态取色（Monet）、多套精选色彩方案、浅色/深色主题，以及英文、简繁体中文、日语和韩语切换。</li>
</ul>

<p><b>使用步骤</b></p>
<ol>
<li>在设备上启动 Shizuku 服务（通过无线调试或 Root）。</li>
<li>打开 App Oops 并授予 Shizuku 权限。</li>
<li>在“应用管理”中查看和调整单个应用的权限模式，或在“规则”页使用批量预设与社区规则。</li>
<li>在“仪表盘”开启“实时拦截守护”，即可获取实时拦截提示与审计日志。</li>
</ol>
